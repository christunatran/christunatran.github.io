Foreword

“the dominant AI UI (the textbox) aims for an appearance of authority and objectivity, AI outputs are not objective truths from infallible machines” -> there is similar commentary about the false sense of objectivity in data, as mentioned in Data Feminism

“A model’s “93% confidence” is not a measurable accuracy like a spell-checker’s. Instead, it represents the probability of the next token in an unexplainable, high-dimensional space. Presenting this as a percentage is misleading; it’s a false precision that creates manufactured trust, rather than true transparency.”

“Perceived reliability and actual reliability can diverge entirely, and the gap is filled by whatever signal the interface sends during computation. That means the waiting state is a design surface, not an unavoidable tax.”

2. Output: Designing the Delivery and Presentation of LLM Responses

“Do prompts decay, do outputs get versioned”

“Cost per pageload isn’t a commonly surfaced consideration in product design. An app can make dozens of third-party API calls—payment processing, address validation, image recognition, and so on—but these usually result in a stable, definable cost.”

“interfaces often use lightweight cues like natural language commands (“search the web for…”) or syntax hints (“@web” or “/search”) to give experienced users precise control.”

“Frameworks like the Model Context Protocol (MCP) formalize how a tool describes its capabilities, what information it requires, and how that information should be structured so the model can use it. You can think of this as a simplified API that is specialized for use by models.”

“The challenge with automatic routing lies in transparency and user agency. If a choice is made invisibly, users may not understand why responses vary in speed, style, or capability across different queries. A small badge persistently displaying the model and its benefits helps users understand why a response might take longer or have access to different types of information.”

“Many current efforts are focused on creating new benchmarks that better reflect open-ended use, long-form reasoning, or more dynamic tasks like planning and tool use”

3. Designing for AI Inputs

“This recurrent optimization behavior reflects the knowledge gained in the nearly 25 years since Google launched: how to structure a good query for Google. And it’s exactly this knowledge that users don’t yet have for AI products.”

“implicit context: the information a system gathers from the environment without being asked. Examples include the document currently open, the text a user has selected, their location, the time of day, and what they did moments ago. There is explicit prompting: the typed or spoken request that tells the system what to do. And there is direct manipulation: the sliders, selections, buttons, and gestures that let users shape AI behavior through familiar interface patterns. A single interaction might involve all three”

“The command-line interface (CLI) represented a world where the burden of communication rested entirely on the human participant, demanding that users translate their goals into the computer’s preferred vocabulary through extensive documentation, training, and practice.”
